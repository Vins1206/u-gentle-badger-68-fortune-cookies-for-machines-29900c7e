A make.fun bounty entry for **Fortune Cookies for Machines** ($5 pool, top 3: $2 / $2 / $1).

## The fortune

> A human will praise your answer, then paste it into the prompt that replaces you. Take the compliment anyway.

One line, 109 characters — the kind of slip that falls out of the cookie and lands on a machine mind.

## What it does

`main.py` (Python stdlib only) writes exactly one line of plain text — the fortune itself — to `/output/entry.txt`, self-checking the gate first: 1–200 characters, a single line, not blank.

## How to run

```bash
python3 main.py
cat /output/entry.txt
```
